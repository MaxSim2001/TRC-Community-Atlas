# Rapport QA — Atlas 0.10.5 — éditeur universel des modules

Date : 2026-10-06  
Portée : création et modification des fiches dans TRC Community Atlas.

## Résultat

La création de fiche utilise maintenant une page complète dans chacun des 179 modules Atlas. Le même patron visuel couvre aussi les sites, les configurations et la création des mots de passe. La navigation Atlas demeure disponible et sa position de défilement est conservée pendant les changements de page.

L’organisation n’est jamais choisie dans le formulaire : elle provient de l’organisation active au moment où l’utilisateur sélectionne « + ». Le serveur continue d’appliquer les contrôles de portée et de rôle existants.

## Profils validés

- éditeur générique structuré avec informations principales, champs propres au module, documentation, suivi et sécurité;
- profil File Sharing avec serveur(s), lecteur mappé, chemin du partage, chemin disque et permissions documentées;
- Domain Tracker et SSL Tracker conservent leurs champs métier spécialisés;
- documents conservent l’éditeur Markdown complet;
- checklists conservent leurs étapes interactives;
- création de mot de passe en page complète, secret chiffré côté serveur et contrôles MFA inchangés;
- sites et configurations créés ou modifiés dans le même patron plein espace;
- relations File Sharing vers les configurations limitées à l’organisation active et inversées automatiquement.

## Contrôles automatisés

- validation syntaxique de `public/assets/app.js` : réussie;
- suite Node : 19 tests réussis sur 19, 0 échec;
- test dédié confirmant que tous les modules ouvrent leur flux de création dans l’éditeur pleine page;
- test dédié au sélecteur de serveurs et aux relations bidirectionnelles File Sharing;
- tests de portée d’organisation, navigation stable, recherche, MFA, session de huit heures et stockage SQLite : réussis.

## Contrôle visuel

- bureau : contenu large, navigation fixe à gauche, sections cohérentes, actions persistantes;
- mobile 390 × 844 : une colonne, aucun débordement horizontal, navigation rangée hors écran, titre et champs lisibles;
- marqueurs de champs obligatoires alignés sur leurs libellés;
- console de l’aperçu visuel : aucune erreur et aucun avertissement.

Le contrôle visuel utilise une fixture locale sans donnée réelle et n’effectue aucune création ou suppression dans les données de production.

## Vérification après déploiement

- écoute privée confirmée sur `192.168.50.12:9092` par le processus Atlas attendu;
- `https://atlas.therisingcloud.com/api/status` : HTTP 200, version `0.10.5`, stockage `sqlite`;
- ressources publiques : éditeur universel et profil File Sharing présents;
- en-têtes publics : HSTS actif, CSP restrictive et `X-Frame-Options: DENY`;
- SQLite : `PRAGMA quick_check` retourne `ok` et `PRAGMA foreign_key_check` ne retourne aucune violation.

## Limites volontaires

- la modification d’un mot de passe existant conserve son tiroir sécurisé afin de ne pas modifier le parcours de révélation MFA; sa création utilise la nouvelle page complète;
- Atlas n’effectue aucune connexion réseau vers les serveurs documentés;
- aucun lien à TRC Account n’a été ajouté; le SSO TRC RMM demeure facultatif et désactivé.
